Примечание:
1- pydivert должен быть установлен: pip install pydivert
2- python должен быть установлен 3.10 или выше
3- Остановка обхода — CTRL+C
4- Обход не идеален, могут быть проблемы с отдельными сайтами
5- Для новичков лучше EXE-версия

# ──────────── Базовые режимы ────────────

# Всё по умолчанию (disorder, midsld, встроенные домены)
python pydpi.py start

# Самый простой режим
python pydpi.py start --mode split

# Разбиение на 3 части (по порядку). Помогает против умных DPI.
python pydpi.py start --mode triple_split

# Разбиение на 3 части в обратном порядке
python pydpi.py start --mode triple_disorder

# Не портить контрольную сумму фейка (если сайты ломаются на fake)
python pydpi.py start --mode fake+split --no-badsum

# Disorder + разрыв в середине домена второго уровня (по умолчанию)
python pydpi.py start --mode disorder --split midsld

# Split + случайная точка разрыва
python pydpi.py start --mode split --split random

# Fake + split (рекомендуется, если disorder не пробивает)
python pydpi.py start --mode fake+split

# Fake + disorder (самый «злой»)
python pydpi.py start --mode fake+disorder

# ──────────── Авто-подбор режима ────────────

# Автоматически перебирает 6 режимов и выбирает самый быстрый для вашего провайдера
python pydpi.py auto


# ──────────── Параметры фейка ────────────

# TTL фейка = 1 (по умолчанию 3)
python pydpi.py start --mode fake+disorder --ttl 1

# Отправить фейк 2 раза (по умолчанию 1)
python pydpi.py start --mode fake+split --repeats 2

# ──────────── Домены ────────────

# Обходить ВСЁ,(осторожно)
python pydpi.py start --all --mode disorder

# Обход всего с fake+split
python pydpi.py start --all --mode fake+split

# ──────────── Диагностика ────────────

# ПОЛНАЯ ДИАГНОСТИКА: права, драйвер, DNS, фаервол и тест пакетов в одной команде
python pydpi.py diagnose

# ──────────── Справка ────────────

# Посмотреть все режимы и примеры
python pydpi.py list-modes

# Версия
python pydpi.py --version

# Полная справка
python pydpi.py --help
python pydpi.py start --help
python pydpi.py auto --help
python pydpi.py diagnose --help
python pydpi.py list-modes --help

# Рекомендуемая последовательность (если не пробивает) 

# 0. Запустите полную диагностику или авто-тест
python pydpi.py diagnose
python pydpi.py auto

# 1. Дефолт (disorder + midsld)
python pydpi.py start

# 2. Split (простой, иногда пробивает там, где disorder — нет)
python pydpi.py start --mode split

# 3. Triple Split (разбиение на 3 части, если DPI склеивает 2 пакета)
python pydpi.py start --mode triple_split

# 4. Triple Disorder (разбиение на 3 части в обратном порядке)
python pydpi.py start --mode triple_disorder

# 5. Fake + split (когда обычный split не проходит)
python pydpi.py start --mode fake+split

# 6. Fake + disorder (наиболее агрессивный)
python pydpi.py start --mode fake+disorder --ttl 2 --repeats 2

# 7. То же, но с random-точкой разреза (если midsld детектится)
python pydpi.py start --mode fake+disorder --ttl 2 --repeats 2 --split random

# 8. Если совсем ничего — обход всего
python pydpi.py start --all --mode fake+disorder --ttl 2 --repeats 3
