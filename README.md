## PY-DPI 

- Утилита для обхода Deep Packet Inspection (DPI). Перехватывает исходящие TCP/UDP-пакеты через WinDivert, распознаёт TLS ClientHello и HTTP-запросы, находит SNI/Host целевого домена и разрезает пакет так, чтобы DPI не смог прочитать домен целиком. 
- Интерфейс — простое окно на Tkinter с логом, статистикой и выбором режима.

## Возможности
- 4 режима обхода:
- split — пакет режется на две части и отправляется по порядку
- disorder — вторая половина уходит первой, первая догоняет с задержкой
- fake+split — сначала отправляется «фейковый» пакет с подменённым SNI и низким TTL, затем нормальный split

- fake+disorder — то же, но с disorder-разбивкой
## Ключевые моменты
- Автоматическое определение SNI в TLS ClientHello и Host в HTTP-запросах.
- Склейка фрагментированных ClientHello (ожидание недостающих сегментов TCP).
- Блокировка QUIC (UDP/443) для принудительного перехода на TCP/TLS.
- Статистика в реальном времени: обработано пакетов, обойдено, отброшено QUIC, в очереди.
- Проверка WinDivert (кнопка «Тест») — убедиться, что драйвер работает.
- Окно «О программе» с кликабельной ссылкой на GitHub.

## Требования
- Windows 10 / 11
- Python 3.8+
- Права администратора
