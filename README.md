## PY-DPI 
- Перехватывает исходящие TCP/UDP-пакеты через WinDivert, распознаёт TLS ClientHello и находит SNI/Host целевого домена и разрезает пакет так, чтобы DPI не смог прочитать домен целиком.

- Интерфейс — простое окно на Tkinter с логом, статистикой и выбором режима.

## Ключевые моменты
- Автоматическое определение SNI в TLS ClientHello и Host в HTTP-запросах.
- Склейка фрагментированных ClientHello (ожидание недостающих сегментов TCP).
- Блокировка QUIC (UDP/443) для принудительного перехода на TCP/TLS.
- Белый список IP для исключения ненужного трафика
- Статистика в реальном времени: обработано пакетов, обойдено, отброшено QUIC, в очереди.
- Проверка WinDivert (кнопка «Тест») — убедиться, что драйвер работает.
- Позиция разреза (Split)
  
· random — случайная позиция внутри домена.

· midsld — середина SLD (например, exa|mple.com).

- Битая сумма фейка — инвертирует контрольную сумму TCP, чтобы сервер точно отбросил пакет.(лучше вкл оставлять)
- Авто-реконнект WinDivert — при сбое драйвера поток-приёмник переоткрывает его до 3 раз с паузой 2 с, не роняя обход. При исчерпании попыток — чистое завершение
- Скорость интернет трафика (идёт ли трафик через PY-DPI)
- Документация (более точное объяснение)
- Fake-повторы (сколько раз отправлять фейк запрос на сервер)
- Режим "Обход всего" (обходит не только домены а любой запрос через 80/443 порты)

## Режимы
- ***split*** Делит ClientHello/HTTP на два TCP-сегмента в позиции разреза. DPI не может прочитать SNI целиком.
- ***disorder*** То же, но вторая половина отправляется первой (с задержкой ~3 мс), первая — повторно. Путает порядок сегментов у DPI.
- ***fake+split*** Сначала отправляются «фейковые» пакеты с подменённым SNI (TTL 1), затем — обычный split.
- ***fake+disorder*** Фейки + disorder. Наиболее агрессивный вариант.

## Диагностика
- Кнопка Тест — открывает WinDivert, 5 секунд считает пакеты, проверяет, что драйвер работает и права выданы.
- Если обход не помогает — попробуй другой режим (начни с disorder, потом fake+split).
- Если рвётся соединение — уменьши fake_repeats / проверь TTL.
- Не забудь выключить VPN/прокси перед проверкой — они меняют картину.
- Проверка DNS на подмену — один раз при старте проверяет до 10 доменов и предупреждает, если DNS адрес попадает в локальные диапазоны (127.0.0.0/8) (Лечится заменой DNS в системе)

## Статистика
Внизу окна:
- обойдено — сколько из них было модифицировано пакетов
- QUIC drop — сколько UDP/443 пакетов выброшено
- Скорость интернет трафика (KB/s)
- pending — сколько соединений ждут досборки ClientHello (когда он пришёл не целиком в одном пакете)

## Тесты (проверка обхода)
Запуск тестов:
 `python -m unittest discover tests -v`
 
 (исходники должны быть рядом)

## Сli (запуск с консоли) (для опытных)
- Примеры
- `python pydpi.py start`
- `python pydpi.py start --mode split`
- `python pydpi.py start --mode fake+disorder`
- `python pydpi.py start --mode disorder --split midsld`
- `python pydpi.py start --mode split --split random`
- `python pydpi.py start --mode fake+split`
- `python pydpi.py start --all`
- `python pydpi.py start --all --mode disorder`
- `python pydpi.py test`
- `python pydpi.py dns`
- `python pydpi.py --help`
- `python pydpi.py start --help`
- `python pydpi.py test --help`

(Полный список в папке cli в файле cmd.txt)

## Требования
- ***Python 3.8+***
- Права администратора
- `pip install pydivert`

## Ограничения
- Только **Windows**
- Блокировки по **IP** не обходит 
- Белые списки не обходит
  
## ⚠️ Предупреждение
- PY-DPI работает через **WinDivert** — тот же драйвер перехвата трафика, что используют Zapret и тд. Однако PY-DPI обрабатывает трафик через **Python**, и поэтому при скачивании больших объёмов или под высокой нагрузкой может работать медленнее.

- При скачивание **EXE-файла** антивирус может расценить как "троян" в таких ситуациях добавьте папку или сам EXE в исключение.
