## PY-DPI 
- Утилита для обхода (DPI). Перехватывает исходящие TCP/UDP-пакеты через WinDivert, распознаёт TLS ClientHello и находит SNI/Host целевого домена и разрезает пакет так, чтобы DPI не смог прочитать домен целиком.

- Интерфейс — простое окно на Tkinter с логом, статистикой и выбором режима.

## Ключевые моменты
- Автоматическое определение SNI в TLS ClientHello и Host в HTTP-запросах.
- Склейка фрагментированных ClientHello (ожидание недостающих сегментов TCP).
- Блокировка QUIC (UDP/443) для принудительного перехода на TCP/TLS.
- Статистика в реальном времени: обработано пакетов, обойдено, отброшено QUIC, в очереди.
- Проверка WinDivert (кнопка «Тест») — убедиться, что драйвер работает.
- Позиция разреза (Split)
  
· random — случайная позиция внутри домена.

· midsld — середина SLD (например, exa|mple.com).
(и то и то может помочь)
- Битая сумма фейка — инвертирует контрольную сумму TCP, чтобы сервер точно отбросил пакет.(лучше вкл оставлять)

## Режимы
- ***split*** Делит ClientHello/HTTP на два TCP-сегмента в позиции разреза. DPI не может прочитать SNI целиком.
- ***disorder*** То же, но вторая половина отправляется первой (с задержкой ~3 мс), первая — повторно. Путает порядок сегментов у DPI.
- ***fake+split*** Сначала отправляются «фейковые» пакеты с подменённым SNI (TTL 1), затем — обычный split.
- ***fake+disorder*** Фейки + disorder. Наиболее агрессивный вариант.

## Диагностика
- Кнопка Тест — открывает WinDivert, 5 секунд считает пакеты, проверяет, что драйвер работает и права выданы.
- Если обход не помогает — попробуй другой режим (начни с disorder, потом fake+split).
- Если рвётся соединение — уменьши fake_repeats / проверь TTL.
- Не забудь выключить VPN/прокси перед проверкой — они меняют картину.

## Статистика
Внизу окна:
- обработано — сколько TLS ClientHello прошло через фильтр
- обойдено — сколько из них было модифицировано
- QUIC drop — сколько UDP/443 пакетов выброшено
- pending — сколько соединений ждут досборки ClientHello (когда он пришёл не целиком в одном пакете)

## Требования
- ***Python 3.8+***
- Права администратора
- `pip install pydivert`

## Ограничения
- Только Windows
- ECH обойти нельзя
- Блокировки по IP не обходит
- Это не VPN/прокси — обход через них обычно более лучше
