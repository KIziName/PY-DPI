## PY-DPI 

- Утилита для обхода (DPI). Перехватывает исходящие TCP/UDP-пакеты через WinDivert, распознаёт TLS ClientHello и находит SNI/Host целевого домена и разрезает пакет так, чтобы DPI не смог прочитать домен целиком. 
- Интерфейс — простое окно на Tkinter с логом, статистикой и выбором режима.

## Ключевые моменты
- Автоматическое определение SNI в TLS ClientHello и Host в HTTP-запросах.
- Склейка фрагментированных ClientHello (ожидание недостающих сегментов TCP).
- Блокировка QUIC (UDP/443) для принудительного перехода на TCP/TLS.
- Статистика в реальном времени: обработано пакетов, обойдено, отброшено QUIC, в очереди.
- Проверка WinDivert (кнопка «Тест») — убедиться, что драйвер работает.
- Окно «О программе» с кликабельной ссылкой на GitHub.

## Требования
- ***Python 3.8+***
- Права администратора
- `pip install pydivert`

## Режимы
- split режется на 2 TCP-сегмента внутри SNI. DPI видит только первый — без SNI.

- disorder Второй фрагмент уходит первым, первый — с задержкой. DPI не может собрать поток.

- fake+split Сначала фейк с чужим SNI и TTL=1 (умирает на первом роутере, DPI его «запоминает»), потом настоящий ClientHello фрагментами.

- fake+disorder То же + disorder. Против самых упрямых DPI.

## Ограничения

- Только Windows
- ECH обойти нельзя
- Блокировки по IP не обходит
- Это не VPN/прокси — трафик идёт напрямую
